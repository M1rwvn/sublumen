# SUBLUMEN - Brand Identity Kit v1.0

AI-powered steganography detection & digital forensics platform.
Tagline: "Find what the pixels hide."

Name rationale: sub (the hidden layer beneath) + lumen (light). The identity
visualizes the product itself: a pixel field whose hidden layer is revealed
under light.

## Logo mark
A rounded tile containing a 5x5 pixel grid. Most pixels sit dim; an amber "S"
is revealed as if lit from beneath, with a subtle light sweep across the tile.

## Files
- sublumen-mark-for-light-bg.svg / -1024.png    dark tile, for light backgrounds
- sublumen-mark-for-dark-bg.svg / -1024.png     light tile, for dark backgrounds
- sublumen-lockup-for-light-bg.svg / -2400.png  mark + wordmark + tagline (light bg)
- sublumen-lockup-for-dark-bg.svg / -2400.png   mark + wordmark + tagline (dark bg)
- sublumen-favicon.svg, sublumen-favicon-32.png, sublumen-favicon-180.png
- sublumen-brand-sheet.png (2400x1680) / sublumen-brand-sheet.svg

All PNGs carry transparent backgrounds around the tile; place on the matching
background color.

## Usage rules
- Clear space: one pixel cell on all sides of the mark.
- Never recolor the amber "S" - it is the revealed layer.
- Minimum mark size: 24 px digital / 8 mm print.
- Wordmark is always two-tone: "sub" in the secondary tone, "lumen" in the
  primary tone.
